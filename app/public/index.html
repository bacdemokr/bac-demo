    GitHub에서 Fork 보기 ↗

    Fork에는 별도의 저장소 생성 권한이 필요합니다. PR 작업에는 Contents·Pull requests 쓰기 권한이 필요합니다. 원본 저장소는 수정하지 않습니다.

    파일 설정도 앱 시작 시 자동으로 읽습니다. GitHub MCP는 OpenClaw의 연결 설정을 사용합니다.

    AI 기능에 사용할 연결 하나만 설정하면 됩니다. 기존 로컬 OpenClaw는 자동 확인합니다. 로컬 모델은 실행 중인 OpenAI 호환 서버 주소를 입력하세요. 연결 시 짧은 응답으로 확인합니다. api.json 설정은 시작할 때 읽으며, 화면에서 입력한 키는 서버 메모리에만 보관합니다.

    설정 안내 ↗

    화면에서 입력한 키는 재시작 시 초기화됩니다. api.json 설정은 시작할 때 자동으로 읽습니다.
