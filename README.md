# Agentic AI Demo

로컬 모델·NVIDIA Inference API·기존 OpenClaw 중 하나에 연결하는 에이전트 데모입니다. 캐릭터를 선택해 대화하거나, 미션 카드에서 브라우저 탐색·에이전트 협업·논문 조회·메시지 연결을 시작하세요.

## 이번 개선

- Resources: 오른쪽 상단에 `bacdemo-tier2`의 `preview/stage3-scenarios` 브랜치(`f1d1215a8c18a72921a35527bcdd8cfc6776c622`) 메뉴를 옮겼습니다. 원본 7개 링크의 이름·순서·주소를 그대로 유지하며, 바깥 클릭·포커스 이동·Esc·링크 선택 시 닫힙니다.

- 에이전트 무대: 입체감 있는 격자, 발광 링, 선택·작업 상태에 연결된 데이터 이동, PM → Dev 인계 애니메이션. 애니메이션 일시 정지와 OS의 동작 줄이기 설정을 지원합니다.
- 작업 유지: 에이전트별 대화와 입력 초안을 보관하고, 대화창을 닫거나 전환해도 진행 중인 작업의 결과를 받습니다. 서버 재시작 시 작업이 초기화됩니다. 페이지 새로고침 시 진행 중인 협업 작업은 다시 추적합니다.
- 대화창: 데스크톱에서는 무대 옆에 열리고 에이전트가 남은 공간에 맞춰 이동합니다. 모바일에서는 아래쪽 창과 두 줄 에이전트 배치를 사용합니다. 무대의 빈 곳 또는 Esc로 닫고, 다른 에이전트를 선택해 전환할 수 있습니다.
- 맛집 찾기: 지역과 메뉴를 입력하면 네이버지도·카카오맵의 실제 검색 목록을 확인합니다. 식당별 평점과 리뷰 수 또는 별점 평가 건수를 표로 비교하고, 지도별 평점순으로 정렬합니다. 이름과 주소를 대조해 같은 식당을 묶고, 다른 지점은 따로 표시합니다. 표시되지 않은 평점은 채우지 않습니다. 확인한 후보 중 상위 20곳을 표시하며, 각 식당의 지도 링크와 조회 시각을 제공합니다. AI 서비스 없이도 동작합니다.
- 질문 기반 조사: 일반 조사·뉴스 정리 중 고릅니다. 요청을 최대 2개의 짧은 검색어로 나누고 읽을 원문을 선택합니다. ‘최근 일주일’ 같은 기간은 검색어에서 빼고 뉴스 검색의 날짜 필터에 적용합니다. 자동 조사에서는 Naver·Daum의 후보를 합치고 중복을 제거한 뒤 본문 최대 3개를 직접 읽습니다. 관련 없는 결과로 개수를 채우지 않습니다. 원문도 주제·게시일을 검증하고, 기간 밖 뉴스나 날짜를 확인할 수 없는 뉴스는 답변 근거에서 제외합니다. 출처 번호와 확인하지 못한 내용을 표시합니다. AI 서비스 없이도 짧은 검색어 생성과 원문 탐색은 동작합니다.
- 아마존 상품 검색: Amazon.com의 실제 상품 목록에서 광고를 제외하고 가격·평점·리뷰 수·상품 링크를 표시합니다. 가격·평점이 없으면 미표시 상태를 유지합니다. 별도 API 키 없이 CDP 브라우저로 동작하며, 사이트가 접근 확인을 요청하면 실제 화면과 오류를 표시합니다.
- 실제 브라우저 탐색: Naver / Daum / Amazon 페이지를 Chromium에서 열고 스크롤합니다. 화면 캡처와 실제 실행 단계, 추출한 링크를 함께 표시합니다. 검색과 요약은 같은 창에서 진행하고 결과를 공유할 수 있습니다.
- 모델 연결: **연결 설정 → 모델**에서 로컬 OpenAI 호환 서버(vLLM, Ollama 등)와 NVIDIA Inference API를 각각 등록하고 사용할 연결을 선택합니다. 서버에서 모델 목록을 읽고 짧은 응답을 확인한 뒤 적용합니다. 선택한 연결은 에이전트 대화·브라우저 조사·PM/Dev 코드 생성에 함께 적용됩니다. 작업 중에는 모델을 변경할 수 없습니다. 기존 OpenClaw 설정도 선택할 수 있습니다. 직접 모델 연결의 GitHub 조회·Fork·PR은 앱의 REST API를 사용하며, GitHub MCP는 기존 OpenClaw 연결에서 사용합니다.
- GitHub 연결: **연결 설정 → GitHub**에 토큰만 입력하면 계정을 자동으로 확인합니다. 공개 저장소를 검색하거나 추천 중 무작위로 골라 **내 계정에 Fork**하고, **이 저장소에서 작업**으로 PM → Dev → PR 시연을 시작합니다. Fork 준비와 원본 연결을 확인한 뒤 내 Fork를 작업 대상으로 선택하며, 원본에는 쓰지 않습니다. 기존 저장소를 바로 사용할 때만 선택 입력란에 `owner/repository`를 넣습니다. 연결·검색만으로 변경하지 않고 Fork 버튼을 누를 때 실제 생성합니다. 기존 파일·환경 설정과 메모리 입력도 지원합니다.
- GitHub 계정 목록·Fork 삭제: **내 저장소 목록**은 작업 대상과 별개로 계정 소유 저장소를 페이지별로 읽어 표시합니다. `ARC-AGI 삭제해줘`처럼 명확히 요청하면 확인창 없이 내 계정의 해당 Fork를 삭제합니다. 모호한 대상·복수 대상·삭제 방법 질문·취소 표현은 실행하지 않습니다. 원본과 다른 계정 저장소는 삭제하지 않습니다. 삭제에는 토큰의 **Administration: Read and write** 권한이 필요하며, Repository creation 권한은 삭제 권한을 대신하지 않습니다. [GitHub 삭제 권한 안내](https://docs.github.com/en/rest/repos/repos#delete-a-repository). 작업 저장소 이름은 키 없이 `.bac/github-target.json`에 보관해 재시작 시 같은 계정에서 복원합니다.
- Telegram 설정: 화면에서 Bot token과 Chat ID를 입력하면 연결을 검증합니다. **메시지 → Telegram**에서 양방향 대화를 제공합니다. 선택한 Chat ID에만 보내고, 해당 채팅에서 온 메시지만 받습니다.
- AgentMail: API key와 기존 Inbox ID를 연결해 받은 메일의 제목·미리보기를 조회하고, 검색·논문 결과를 이메일로 공유합니다.
- 결과 공유: 보낼 내용과 목적지를 확인·수정한 뒤 사용자가 보내기를 누르면 전송합니다. 연결 또는 조회만으로 메시지를 발송하지 않습니다.
- 실행 기록: 실제 브라우저 단계와 gateway 요청·응답, 메시지 전달 결과를 표시합니다. gateway 내부의 개별 MCP 도구 호출까지 추적하는 로그는 아닙니다.

| Agent | 기능 | 실제 연동 방식 |
| --- | --- | --- |
| HealthAgent | GPU·디스크 상태 | 로컬 명령 + 선택한 AI 모델 요약 |
| GitHubAgent | 저장소 조회; MCP 설정 시 이슈·PR 도구 요청 | GitHub API + AI 요약; 도구 작업은 OpenClaw `git` 에이전트의 MCP |
| OrchestratorAgent | PM 계획 → Dev 구현 → PR | 선택한 AI 모델 + GitHub REST API |
| ArxivAgent | 논문 모음·분 단위 확인 | arXiv RSS + 캐시; 피드가 비면 참고 논문임을 표시 |

MCP, CDP, REST API는 서로 다른 연동 방식입니다. 이 데모는 이를 구분해 표시하며, 모든 기능을 MCP 도구 호출로 설명하지 않습니다. GitHub 도구가 실제 설정됐는지는 저장소 조회 등의 요청으로 확인하세요.

## 실행

Node.js 20.6 이상이 필요합니다. `.env` 복사와 OpenClaw 설치는 필수가 아닙니다. 새로 설치할 때는 [설치 안내](INSTALL.md#처음-실행)의 명령을 사용하세요. 로컬 모델 서버는 별도로 실행해야 하며, 기본 예시 주소는 `http://127.0.0.1:8001/v1`입니다. 앱의 8000번 포트와 겹치지 않게 지정하세요. 프로젝트 폴더에서 아래 명령으로 실행합니다.

```bash
./bac start
```

[http://127.0.0.1:8000](http://127.0.0.1:8000)에서 열립니다. 첫 실행에는 앱 패키지를 설치하며, 설치된 Chrome/Chromium을 찾아 브라우저 탐색도 준비합니다. 실행 중인 CDP 브라우저가 있으면 연결해 사용합니다. **`./bac stop`** 또는 **Ctrl+C**로 앱과 이 명령이 시작한 브라우저를 종료하며, 기존 브라우저와 OpenClaw는 계속 실행됩니다. 종료 후 앱 포트가 닫혔는지도 확인합니다. 상태 확인은 `./bac status`, 다른 포트는 `./bac start --port 8001`입니다. 다른 포트로 실행한 앱은 `./bac stop --port 8001`처럼 종료합니다. 브라우저 준비를 생략하려면 `--no-browser`, 별도 설정 파일은 `--config /path/to/api.json`을 사용하세요. `.env`도 자동으로 읽습니다.

AI 응답에는 기존 OpenClaw·로컬 모델·NVIDIA API 중 하나만 연결하면 됩니다. 시스템 지표·논문 목록·맛집 및 아마존 검색은 AI 모델이나 서비스 키 없이 사용할 수 있습니다. GitHub·Telegram·AgentMail은 사용할 기능만 연결하세요. 상세 설정은 [INSTALL.md](INSTALL.md)를 참고하세요.

## API 한 번에 설정하기

파일 편집도 선택 사항입니다. **연결 설정**에서 사용할 서비스만 입력해 바로 사용할 수 있습니다. 재시작 후에도 유지하려면 첫 실행에 자동으로 준비되는 `api.json`에 저장하세요. 사용할 서비스의 항목만 채우고 `./bac start`를 실행하세요. 연결을 시작 시 검증하므로 화면에서 키를 다시 넣을 필요가 없습니다. 빈 키는 미설정으로 처리하며, 기존 환경변수·토큰 파일을 계속 사용하거나 화면에서 연결할 수 있습니다.

```json
{
  "github": { "token": "GitHub PAT" },
  "telegram": { "botToken": "BotFather 토큰", "chatId": "숫자 Chat ID" },
  "agentmail": { "apiKey": "AgentMail 키", "inboxId": "my-agent@agentmail.to" }
}
```

화면 입력이 현재 연결을 바꾸며, 재시작하면 `api.json` 설정을 다시 적용합니다. `api.json`의 값이 기존 환경변수·토큰 파일보다 우선합니다. 파일을 수정한 뒤에는 앱을 재시작하세요. 실제 키가 든 `api.json`은 Git에서 제외하고, 배포에는 빈 `api.example.json`만 포함합니다. 연결 확인은 메시지 발송이나 GitHub 변경을 실행하지 않습니다. OpenClaw는 로컬 설정을 자동으로 찾습니다. OpenClaw에 별도 등록한 `scripts/github-mcp.sh`도 시작할 때 같은 파일의 GitHub 토큰을 읽습니다. 화면 입력으로 이미 실행 중인 MCP 인증을 바꾸지는 않습니다.

## 모델 설정

런타임의 **연결 설정 → 모델** 또는 `api.json`의 `models` 항목으로 설정합니다. 모델 ID는 해당 서버가 `/v1/models`에서 반환하는 정확한 ID를 사용하세요.

```json
"models": {
  "active": "local",
  "local": {"baseUrl": "http://127.0.0.1:8001/v1", "model": "YOUR_LOCAL_MODEL", "apiKey": ""},
  "nvidia": {"baseUrl": "https://inference-api.nvidia.com/v1", "model": "YOUR_NVIDIA_MODEL", "apiKey": "YOUR_API_KEY"}
}
```

`active`는 `local`, `nvidia`, `gateway` 중 하나입니다. 기존 설정 파일에는 models를 추가하지 않아도 기존 OpenClaw 연결을 사용합니다. 파일로 설정하면 시작 시 모델 목록을 확인하며, 검증 실패 시 다른 모델로 자동 전환하지 않습니다. 런타임 변경은 파일을 수정하지 않습니다. 사내 Inference Hub는 `https://inference-api.nvidia.com/v1`, 공개 NVIDIA API Catalog는 `https://integrate.api.nvidia.com/v1`을 사용합니다. 해당 서비스의 API 키를 입력하세요. 주소를 변경하면 기존 키를 다른 서버로 전달하지 않습니다.

## 권장 시연 흐름

1. 앱을 시작하면 실행 중인 로컬 OpenClaw를 자동 확인합니다. 없으면 **연결 설정 → 모델**에서 로컬 모델 또는 NVIDIA API 중 하나를 연결합니다. **연결 설정 → GitHub**에 토큰만 연결하고 공개 저장소를 검색·추천에서 선택해 Fork합니다. Fork 완료 후 **이 저장소에서 작업**을 누릅니다. Telegram·AgentMail은 결과 공유가 필요할 때 연결합니다.
2. **브라우저 탐색 → 맛집 찾기**에서 지역(예: 성수동)과 메뉴(예: 파스타)를 입력합니다. 네이버지도·카카오맵 검색 후 비교표에서 원하는 지도의 평점순으로 바꿔 볼 수 있습니다. 지도별 검색 순위가 달라 같은 식당을 두 곳에서 모두 확인하지 못할 수 있습니다.
3. **아마존 상품 검색**에서는 짧은 상품명(예: USB C hub)을 입력해 실제 Amazon.com 검색 화면과 광고를 제외한 상품 가격·평점·리뷰 수를 확인합니다. 가격은 화면에 표시된 통화이며 배송비·세금은 제외합니다. 접근 확인이 나타나면 오류와 실제 화면을 표시합니다. 별도 API 키는 필요 없습니다.
4. 일반 조사·뉴스 정리로 전환하면 기존 질문 기반 조사를 사용할 수 있습니다. 검색어 계획 → 여러 검색원 확인 → 원문 방문 → 근거 답변 순서로 진행됩니다. 출처 번호로 원문을 확인할 수 있습니다. AI 서비스가 일시적으로 응답하지 않으면 읽은 근거를 먼저 확인하고 복구 후 **AI로 정리**할 수 있습니다.
5. **결과 공유**에서 내용을 확인하고 Telegram 또는 이메일로 보냅니다.
6. **에이전트 협업**에서 기능을 요청하면 PM의 계획과 Dev의 PR 생성 과정을 볼 수 있습니다. 기존 동작대로 대상 저장소에 실제 브랜치·커밋·PR이 생성됩니다.

## 연결 정보

연결된 서비스는 계정·받은편지함과 **연결됨** 카드로 표시하고, 키 입력란은 숨깁니다. **연결 정보 변경**에서 입력란을 열고 **변경 취소**로 원래 연결을 유지할 수 있습니다. 설정을 불러왔지만 인증·네트워크 확인이 필요한 경우에는 별도 상태로 표시하며, 키를 다시 입력하도록 요구하지 않습니다.

앱 시작 시 실행 중인 같은 사용자 소유의 OpenClaw 서비스와 `~/.openclaw/openclaw.json` 설정을 확인합니다. 사용자 프로필과 `OPENCLAW_CONFIG_PATH` / `OPENCLAW_STATE_DIR`도 지원합니다. 인증 정보는 서버에서 읽고, 화면에는 입력란이나 연결 버튼을 표시하지 않습니다. 발견한 설정 **경로만** `app/.openclaw-path`에 보관해 다음 시작에서도 사용하며, 토큰은 복사하지 않습니다.

실제 설정된 에이전트 이름을 사용합니다. `bac`가 없으면 기본 에이전트를 사용하고, PM / Dev의 텍스트 생성도 각 에이전트가 없으면 기본 에이전트로 전달합니다. `git` 에이전트가 없어도 GitHub 토큰을 연결하면 선택한 저장소의 메타데이터를 API로 읽고 기본 AI 에이전트가 설명합니다. 이때 역할은 **저장소 조회 · GitHub API**로 표시하며, 이슈·파일 도구 작업을 수행했다고 설명하지 않습니다. MCP 도구 작업에는 설정된 `git` 에이전트가 필요합니다. `GATEWAY_AGENT`, `GITHUB_AGENT`, `PM_AGENT`, `DEV_AGENT`로 이름을 지정할 수도 있습니다.

다른 서버의 OpenClaw를 사용할 때는 서버 실행 환경에 `GATEWAY_URL` / `GATEWAY_TOKEN`을 설정합니다. 원격 주소에 로컬 설정의 토큰을 자동으로 전달하지 않습니다. 기존 토큰 파일도 계속 지원합니다. Telegram·AgentMail에 화면에서 입력한 키는 이 데모 서버의 메모리에만 저장하며, localStorage·쿠키에는 저장하지 않습니다.

이 서버는 한 명의 시연자가 사용하는 로컬 앱입니다. 여러 브라우저 탭은 같은 연결을 공유합니다. 기본 localhost 바인딩을 유지하세요. 다중 사용자 서비스로 배포하려면 인증과 사용자별 연결 격리를 추가해야 합니다.

기존 환경변수와 토큰 파일도 지원합니다. `api.json`, `.env`, `app/.gw_token`, `app/.gh_token`, `app/.tg_token`을 커밋하지 마세요. 환경변수로 AgentMail을 연결하려면 `AGENTMAIL_API_KEY`, `AGENTMAIL_INBOX_ID`를 설정합니다. Telegram은 별도 봇의 token과 `TG_CHAT_ID`를 함께 지정합니다.

GitHub의 화면 입력은 파일·환경 설정보다 우선합니다. 연결 해제는 앱의 메모리 연결을 비우며, 설정 파일을 삭제하지 않습니다. 다음 앱 시작에서는 `api.json`과 기존 설정을 다시 읽습니다. 협업 작업이 진행 중이면 연결 변경을 막고, 시작 시 선택한 저장소와 인증으로 해당 PR 작업을 마칩니다. 연결 확인은 계정·저장소 조회이며 토큰의 쓰기 권한을 실제 변경으로 시험하지 않습니다. PR 생성용 토큰에는 Contents와 Pull requests 쓰기 권한이 필요합니다.

## 검증

```bash
npm test
# 로컬 Chrome/Chromium 설치 필요
TEST_CHROMIUM_EXECUTABLE=/path/to/chromium npm run test:browser
```

연결 검증·취소 경쟁·발송 조건·작업 조회 재시도·Gateway 오류·HTTPS·잘못된 요청 거부를 테스트합니다. 브라우저 테스트는 로컬 fixture로 데스크톱·모바일 UI, 대화 전환 중 지연 응답 유지와 실제 CDP 탐색·스크롤·링크 추출·JPEG 캡처, 다중 검색원 병합·원문 읽기·출처 검증을 확인합니다. 접근이 막힌 원문을 건너뛰고 다른 후보를 읽는 동작도 확인합니다. 맛집 기능은 실제 DOM 평점 추출, 광고 제외, 리뷰·평가 건수 구분, 지점 병합, 누락값과 지도 접근 실패, 정렬·공유 미리보기·모바일 표를 검증합니다. 실제 Telegram / AgentMail 계정 또는 Spark gateway로 보내는 테스트는 포함하지 않습니다.
